# Code of Conduct

## Our Standard

Contributors are expected to maintain a respectful, professional and constructive environment.

## Expected Behavior

- Be respectful and inclusive.
- Give constructive feedback.
- Focus discussions on technical and project goals.
- Respect different experience levels.
- Accept reasonable technical disagreement.

## Unacceptable Behavior

- Harassment or discrimination.
- Personal attacks.
- Threats.
- Deliberate disruption.
- Publishing private information without permission.

## Reporting

For serious conduct concerns, contact the project maintainer through the repository's available communication channels.
