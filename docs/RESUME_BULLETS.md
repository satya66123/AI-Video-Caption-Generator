# Resume Bullets

## Detailed

- Built an AI-powered video caption generator using Python, Streamlit, Whisper, Ollama, TranslateGemma and FFmpeg.
- Implemented an end-to-end video → transcription → language detection → translation → SRT/VTT → captioned-video workflow.
- Built a provider-based translation architecture supporting local Ollama/TranslateGemma.
- Generated timestamp-preserving SRT and VTT subtitles.
- Integrated FFmpeg to permanently burn captions into a separate output video while preserving the original.
- Developed Dashboard, Settings, Help and About pages with sidebar navigation.
- Added robust validation and error handling for caption and translation workflows.
- Built a comprehensive PyTest suite with 145 passing tests and GitHub Actions CI.

## Short

Built a local-first AI video caption generator with Python/Streamlit, Whisper, Ollama, TranslateGemma and FFmpeg, delivering multilingual SRT/VTT and captioned-video output with 145 passing tests.
