# 🔄 Complete Visual Workflow

```text
📤 Upload Video
      ↓
💾 Save Original Video
      ↓
🎙️ Whisper Transcription
      ↓
🌐 Language Detection
      ↓
💬 Select Caption Language
      ↓
🤖 Ollama / TranslateGemma
      ↓
📝 Generate Captions
      ↓
📄 SRT + VTT
      ↓
🔥 FFmpeg Caption Burning
      ↓
🎥 Captioned Video
      ↓
📊 Dashboard / Outputs
```
