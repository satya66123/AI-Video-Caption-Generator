# Security

## Principles

- Do not commit secrets.
- Do not commit private video files.
- Do not commit credentials or API keys.
- Keep generated media out of version control unless intentionally included.

## Local Processing

The core translation workflow uses local Ollama.

## User Data

Uploaded videos and generated outputs are stored locally by the application.

## Reporting a Security Issue

Do not publish sensitive vulnerability details publicly before coordinating with the maintainer.

Contact the project maintainer through the repository's private communication options where available.
